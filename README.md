# Кулинар и фуд-блогер — страница-визитка

Одностраничный сайт кулинара и фуд-блогера: подборка фирменных блюд с временем
приготовления и калорийностью, галерея ингредиентов недели и форма обратной связи.

## Для кого

- Читатели блога, которые ищут рецепты и хотят быстро оценить сложность блюда.
- Заказчики и бренды, подбирающие автора для съёмки или разработки рецептов.
- Сам автор — как компактное портфолио с постоянной ссылкой.

## Функциональность MVP

- Блок «О себе» с фотографией фирменного блюда.
- Список навыков автора.
- Карточки «Фирменные блюда»: фото, название и пара «Время / ккал».
- Галерея «Ингредиенты недели»: фото, название и польза каждого ингредиента.
- Боковой блок с любимой кухней автора.
- Форма обратной связи: имя, email, сообщение.
- Навигация по разделам и раскладка, работающая на телефоне, планшете и десктопе.
- Приветствие посетителя по имени и сводка по калорийности блюд (JavaScript).

## Запуск

Откройте `index.html` в браузере. При загрузке страницы появится окно с запросом
имени, после чего будет показано приветствие и сводка по калорийности.
Подробные результаты расчётов выводятся в консоль браузера (F12 → вкладка Console).

    ├── garlic.png
    └── lemon.png

Скрипт `js/script.js`
Работает с массивом `calories` — калорийностью блюд (в ккал):

* запрашивает имя посетителя и показывает приветствие (если имя не введено, подставляется «гость»);
* считает суммарную калорийность и калорийность блюд свыше 600 ккал, результат показывает через `alert`;
* выводит в консоль самое калорийное блюдо, список высококалорийных блюд, количество и долю низкокалорийных (≤ 300 ккал);
* при общей калорийности более 3000 ккал советует распределить рацион на 2 дня.

Вспомогательные функции: `sum`, `max`, `filterOver`, `countLight`.
